# sys1rust

Run System 1 decision models (Laya) locally on Apple Silicon. Rust + MLX, no Python at run time. `sys1d` serves the same `POST /v1/systemone` API as upstream `laya serve`.

The code is arriving as a series of pull requests so each part gets reviewed. This README grows with them.

Apache-2.0. See `NOTICE` for where the code comes from.
